## 真实服务与样片限制

- 豆包已实现公开合约与错误测试，未使用真实凭据调用；faster-whisper、官方 Qwen ForcedAligner 未在本轮真实运行。
- Suno 未配置。合成测试用合成正弦音，明确仅为测试，未交付为音乐。真实录屏样片没有配乐。
- 封面复用本录屏前次 Codex 内置生图结果；本轮没有重复生图，也未实测第三方图片 API。
- 有一处原对象名称两次 ASR 识别不一致（ISSS/iOS）；字幕使用“它”暂代，已在 HTML 明示待听核。整段语音未人工听审，audio_review 保持 pending。
- 不包含平台上传、远端发布或市场收录验收。

## 复现

先按 SKILL.md 准备字体与运行环境，然后：

```bash
python -m unittest discover -s tests -v
python tests/smoke_render.py
```

集成测试生成独立临时目录，使用 FFmpeg 合成测试画面与音频，不依赖个人录屏文件。字体、模型和测试视频不打包进 skill。
