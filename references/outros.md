# 片尾与关注引导

调研日期：2026-10-11。

片尾的任务是给出一个下一步，不是重新介绍整份履历。默认只显示姓名、内容承诺和 1–3 个稳定入口：向阳乔木、把 AI 前沿变成可用工作流、X `@vista8`、GitHub `@joeseesun`、`qiaomu.ai`。公众号方案使用「向阳乔木推荐看」及 `qiaomu-profile` 中的公开二维码。禁止使用未经实时核验的粉丝数、项目数量和头衔指标。

## 四套固定方案

| 设置 | 风格 | 推荐用途 |
|---|---|---|
| `terminal`（固定默认） | 动画终端、头像、打字效果、X/GitHub 图标；“向阳乔木 / 乔帮主” | AI coding、产品演示和开发者项目 |
| `pulse` | 深色荧光、头像、内容承诺和社交账号 | AI 工具录屏的静态备选 |
| `editorial` | 米白杂志、强排版、头像 | 知识讲解、GEO、产品判断 |
| `community` | 紫色光晕、公众号二维码 | 微信/B站社区增长；手机端看视频时二维码不应作为唯一入口 |
| `none` | 无片尾 | 极短演示、需要无缝循环或用户明确不要 CTA |

默认 6 秒：约 3 秒完成入场动画，完整片尾定格约 2.15 秒供阅读，再用 0.7 秒渐隐至黑，并保留约 0.15 秒纯黑尾帧。动画完成后的完整画面必须至少稳定展示 2 秒，不能边完成边立即退出。这个时长处于 YouTube 原生结束画面 5–20 秒区间；需要摆放推荐视频与订阅组件的 YouTube 长视频可延长到 8–12 秒。账号区固定显示 X `@vista8`、GitHub `@joeseesun`、公众号「向阳乔木推荐看」和网站 `qiaomu.ai`，分别使用 X、GitHub、微信双气泡和网站地球图标；去掉 Blog。

竖屏必须使用原生 9:16 重排：头像居中，X/GitHub 改为纵向账号列表，文字和 CTA 保持在中央安全区，为顶部标题区与底部平台控件留白。横屏使用左右布局。项目渲染按源画布自动生成完全匹配的片尾；需要独立分发资产时使用 `--variants` 生成 1920×1080 与 1080×1920 两个 MP4，不能互相强裁。

口播若自然收束，优先用内容相关 CTA，例如“想看完整实现，关注我，下一期继续”；不要每条机械朗读所有账号。没有录制 CTA 时，片尾卡和配乐即可，不用合成新语音。平台差异：YouTube 以“继续看下一条/订阅”为主；B站以“关注、收藏、三连”择一，不堆三个同权按钮；公众号方案强调扫码或搜索账号。

配乐必须覆盖整个片尾和末尾黑场，不能在人声结束时突然消失。正片讲话结束后，侧链压低效果以约 400ms release 自然解除，让配乐轻微恢复；随后使用半正弦曲线淡出至静音。默认淡入 0.5 秒、淡出 3 秒；在片尾完成主要动画时开始收束，并与画面渐隐共同归零。最终仍按 -17 LUFS-I 和真峰值规则验收。FFmpeg 与 Adobe 文档只规定淡出机制，不规定统一秒数；3 秒是本 skill 针对轻配乐录屏的听感默认值，后续可按音乐节奏调整到 2–4 秒。

X 必须使用官方 X 标志的非对称字形轮廓，不能用两条普通对角线模拟。GitHub 固定使用 GitHub 官方 Primer Octicons 的 `mark-github-24` 轮廓，禁止手绘猫耳、头部或尾巴；允许放在品牌配色圆底中提高深色画面的识别度。微信固定使用完整双气泡轮廓与四个圆点，放入 `#07C160` 品牌绿圆角方块，内部为白色；禁止画成通用聊天气泡、单气泡或改成荧光黄。各图标保持同高和相近视觉重量并保留净空，可随整行淡入/移动，但不单独拉伸、旋转、重绘或变形。参考 [X 官方品牌工具包](https://about.x.com/en/who-we-are/brand-toolkit)、[GitHub Brand Toolkit](https://brand.github.com/foundations/logo)、[Primer Octicons](https://github.com/primer/octicons) 和仓库内固定矢量 `assets/icons/`。
