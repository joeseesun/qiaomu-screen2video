# 录屏教程剪辑方法

剪辑先服务理解，再服务刺激。每个切换、文字和声音都必须回答一个问题：观众此刻该看哪里、该记住什么、为什么值得继续看。不能回答就删除。

## 决策顺序

1. **承诺**：开头尽快兑现标题和封面承诺，先让观众看到结果或最强证据，再解释过程。
2. **故事**：把讲述压成 hook → body → close。body 按“动作 → 结果 → 下一步”推进，不按素材原始顺序机械保留。
3. **注意力**：先保真实界面和鼠标，再用聚光框、箭头或逐词高亮引导视线。装饰不能与操作抢注意力。
4. **节奏**：在语义变化、操作完成、结果出现或情绪转折处切换；不按固定秒数塞转场。连续画面能说明问题时保持安静。
5. **连续性**：音乐和讲述应跨视觉切换连续流动；章节切换可借鉴 J/L cut，让声音先行或延续，避免画面和音频同时硬断。

这对应 Walter Murch 的优先级：情绪、故事、节奏优先于形式连续性。录屏教程中的“情绪”通常是期待、确认和完成感；“故事”是问题、操作、证据和结果；“节奏”来自讲述重音、鼠标动作与界面状态变化。

## 视觉层级

同一时刻只允许一个主视觉：真实操作、界面指引、关键词花字、章节卡四者取其一；逐词高亮可以辅助，但不能制造第二个注意中心。

- **真实操作**：界面正在变化时，尽量不盖全屏章节卡。
- **界面指引**：观众可能找不到按钮、参数或结果时使用；目标来自实际帧。
- **逐词高亮**：只给数字、专名、动作和结论，跟随发音，不连续把整句染色。
- **关键词花字**：把一句话压成一个记忆点，通常 2–8 个中文字符。
- **章节卡**：只在结构真正切换、画面进入自然停顿时使用。短于 60 秒的成片默认最多一张。

## 最终时间轴

任何阅读时间都在最终成片中计算，不能直接拿原素材秒数判断：

`最终可见时长 = (原素材 end - start) / speed`

推荐范围：

| 元素 | 最终可见时长 | 说明 |
|---|---:|---|
| 逐词高亮 | 真实词时间 | 入退场要比发音短，不拖尾 |
| 关键词花字 | 0.8–1.6 秒 | 进入约 0.12–0.18 秒 |
| 界面指引 | 1.2–3.5 秒 | 至少留下约 1 秒稳定定位时间 |
| 全屏章节卡 | 2.2–4.0 秒 | 绝对不得短于 1.8 秒 |

章节卡建议阅读时间：`max(标题字符数 / 7, 英文字符数 / 17) + 0.8 秒`，最低 2.2 秒、最高 4.0 秒。中英两种语言取较慢者，不相加。入场约 0.18–0.24 秒、退场约 0.22–0.28 秒，完整停留阶段不得小于 1.2 秒。若素材没有足够空隙，改用花字或界面指引。

## 教程结构

- **Hook**：用实际结果、明显前后对比或一句具体承诺开场；封面标题与前几秒必须一致。
- **Body**：每一段只完成一个认知任务。先让观众看到操作对象，再说动作，最后显示结果。
- **Close**：收束成一句可复述的结论，再进入关注引导。片尾不重复讲解，不突然切断音乐。

快节奏不等于一直动。TikTok 的文字、动作、转场和声音用于维持注意力，但教学视频必须服从认知负荷：删除与学习目标无关的动效；用信号提示相关区域；在有意义的边界分段。

## 验收

1. 以最终 1× 播放完整观看一次，记录任何“没读完、找不到、被遮住、被音效吓到”的时刻。
2. 每张章节卡检查入场中点、完整停留和退出前一帧；看得见不等于读得完。
3. 每个聚光框检查目标进入、稳定、离开三帧，确保目标没有移动出框。
4. 静音看一遍，视觉层级仍应清楚；只听音频一遍，讲述和音乐应连续、片尾自然归零。
5. 发布后看留存曲线：下坠处检查承诺落空、重复、遮挡或节奏中断；回看高峰可能是精彩，也可能是信息不清。下一条视频只调整有证据的问题。

## 依据

- [YouTube 关键留存时刻](https://support.google.com/youtube/answer/9314415)：用平段、下坠、峰值和回看分析内容是否清楚、是否值得继续看。
- [YouTube 内容表现与推荐](https://support.google.com/youtube/answer/16559650)：开头尽快兑现标题与缩略图承诺，并持续提供价值。
- [TikTok Creative Codes](https://ads.tiktok.com/business/en/creative-codes)：hook–body–close；文字、动作、转场和声音用于有目的地维持注意力。
- [Netflix 字幕时间规范](https://partnerhelp.netflixstudios.com/hc/en-us/articles/360051554394-Timed-Text-Style-Guide-Subtitle-Timing-Guidelines)：避免闪现文字，较长内容尽量延长屏幕时间并完整回看。
- [Netflix Subtitle Templates](https://partnerhelp.netflixstudios.com/hc/en-us/articles/219375728-Timed-Text-Style-Guide-Subtitle-Templates)：成人英文参考上限 17 字符/秒；本 skill 将它作为章节卡英文阅读时间的保守基线。
- [多媒体学习的连贯、信号与邻近原则](https://www.researchgate.net/publication/262915119_Principles_for_reducing_extraneous_processing_in_multimedia_learning_Coherence_signaling_redundancy_spatial_contiguity_and_temporal_contiguity_principles)：删去无关刺激，用提示把注意力导向关键内容。
- [动画中的信号与分段研究](https://onlinelibrary.wiley.com/doi/10.1002/acp.1348)：有意义分段可降低认知负荷，信号应服务任务相关信息。
- [Adobe Premiere J/L cuts](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)：声音与画面错开切换可保持连续性。
- [TechSmith 工作流视频实践](https://www.techsmith.com/blog/best-ways-to-document-workflows/)：放大或高亮光标，并用箭头与标注让步骤容易定位。
