# 编辑风画板样式（editorial-plate）

来源：2026-10-16「乔木 AI RSS 音频功能介绍」录屏，从 v1 到 v12 共 12 轮、与用户逐条对照后留下来的做法。**默认样式不变**（电影字幕式 `overlay`）；用户要“Vercel / 纽约客那种克制又精致、不要 AI 味”时选这套。组件在 `scripts/editorial_ass.py`，完整构建过程存档在 [examples/rss-audio](examples/rss-audio/README.md)。

## 一句话定位

克制的结构 + 一两处张扬的版面。结构来自 Vercel（纯黑纯白、等宽小字、发丝线、弹簧缓动），气质来自纽约客（白底黑字衬线大标题、细线分栏）。

## 固定的是结构，可变的是皮肤

**不要把这次的选择当成规则。** 蓝色只是这次三个方向里用户觉得还行的一个，不是这个样式的“标准色”。

| 固定（结构，违反就不精致） | 可变（皮肤，每个视频按内容选） |
|---|---|
| 信息层级、对齐网格、字幕与标签的间距 | **强调色**（见下，用 `Palette`） |
| 强调色只有一个、只表示“看这里” | 画布明暗（黑底画板 / 白底画板）、纸面是纯白还是别的底 |
| 三条动效缓动、进场快出场更快、错峰 | 字体搭配（宋体 / 黑体 / 圆体，等宽或不用等宽） |
| 介绍卡不透明、不贴边；不叠第二套镜头 | 版式拓扑（字幕带在下方 / 侧边 / 叠加）、开场是大字还是别的形式 |

选法：按内容定一个强调色（例：Obsidian 题材偏紫，金融偏绿，品牌片用品牌色，克制到极致就 `mono-none` 不用强调色），然后**先出 3 个方向的静帧并排给用户选**，不替用户定。代码里 `Ass(palette="mono-vermilion")` 或 `palette_from_hex("#8B7CFF")` 即可整体换色；预置：`mono-blue`（本次）、`mono-vermilion`（乔木品牌朱红）、`mono-violet`、`mono-emerald`、`mono-none`。

## 画面系统（1920×1080 脚本坐标，输出 1080p 或 4K 都按同一份 ASS 缩放）

| 项 | 规则 |
|---|---|
| 配色（本次选择，可换） | 纯黑 `#000`、纯白 `#FFF`、**唯一强调色**。本次用 Vercel 蓝（黑底 `#3291FF`，白底 `#0070F3`）。这个用户对本片明确不要奶色，对别的片未必；强调色是否用品牌朱红也由内容决定 |
| 画板 | 录屏裁成 16:9 缩进画板：`x=217 y=22 w=1486 h=836`，四角圆角 14，黑底。不加投影、不加边框 |
| 字幕带 | 画板下方整段黑带，字幕**不压画面**。中文 y=912（霞鹜新晰黑 52，暖灰），英文 y=964（Atkinson SemiBold 34，灰）。位置全程固定，不因字数变 |
| 进度 | 贴着底边：标签 y=1030，细线 y=1058（4px）。字幕与标签之间至少留 36px（实测 4px 时用户立刻指出“太近”） |
| 字体分工 | 大标题宋体粗（Songti SC）；小标签等宽（Menlo）；字幕无衬线。**Menlo 没有中文字形**，含中文的等宽样式行必须用 `\fn` 换成无衬线，否则出方块 |
| 强调 | 字幕里只有关键词变蓝；其余一律不变色 |
| 产品朗读句 | 插件自己念出来的句子用宋体加「」，与本人说话区分 |

## 动效令牌（全片只用这三条）

- 进场 `1-2^(-10u)`，0.28–0.42 s；卡片可加 ≤6% 过冲。
- 出场 `u^3`，比进场短（0.2 s）。
- 错峰：子元素依次晚 30 / 60 / 100 ms；字幕上浮 10px，标题上浮 22px，同时淡入。
- 线性匀速移动一律不用（像 PPT）。ASS 的 `\move` 是线性的，缓动靠逐帧 `\pos` 事件实现（`Ass.add` 会自动做）。

## 组件

1. **整页大字开场**（`cold_open_karaoke`）：片头用产品自己念出来的那一句。整页白底、三行 ~200px 宋体大字，念到哪个字哪个字从浅灰变黑（`\kf`，时间用 ASR 逐字时间），底部只留一行英文和页脚。不要标题、副题、引语、光晕——开场就是在演示“朗读时高亮跟读”。
2. **章节进度线**（`chapter_progress`）：每章一段细线，宽度 = 40% 按时长 + 60% 平均（5 秒的章也放得下标签）；当前章白色填充随时间走，**圆点正好压在线中心**；标签 `01  听文章`，当前章亮白。圆点路径用正坐标 + `\an7`，别用负坐标 + `\an5`（实测会偏到线上方）。
3. **章节介绍卡**（`detached_card`）：不透明近黑、四角圆角、与画板边缘留 28px、细边加轻投影；编号（蓝等宽）/章名（宋体）/一行说明。**禁止半透明**（底下 UI 透出来，字发灰发脏），**禁止贴着画板边缘长出来**（会和上沿连成一体）。
4. **点击涟漪**（`plate_render.py --click`）：蓝圈 + 白圈，0.65 s 扩散淡出。只给**逐个看过帧确认**的点击加；悬停高亮和录屏软件自带缩放会被“界面变化”启发式当成点击，宁少勿错。
5. **片尾搜索卡**（`outro_search`）：白页，大标题“去插件市场，搜索”，搜索框逐字打出关键词，出现插件卡片和黑色安装按钮，右栏作者与账号。成对做“带引导 / 无引导”两版，无引导版只定格 1 秒并淡出。
6. **封面首帧**：封面图作为视频第一帧停 0.5 秒，同时用 `-disposition:v:1 attached_pic` 嵌为文件封面。

## 速度、响度与字幕停留

- 讲述 1.4×；产品自己朗读/试听音色的片段保持 1.0×（加速会听不出音色差别）。章节卡在最终时间轴上换算。
- 整片 -16～-17 LUFS；配乐 -16 dB 左右，讲话时侧链压低；章节切换轻“叮”（≤ -20 dB）。
- 双语字幕按 `max(原时长, 英文字数/19)` 延长停留，但不越过下一句开始前 0.04 s；加速后中文超过 9.5 字/秒要缩句。
- ASR 听错的词必须对照界面文字改（本次把界面里的“读者提交”识别成了“作者提交”）。

## 不要做（每一条都被用户否过）

| 做法 | 为什么 |
|---|---|
| 叠加自己的跟随放大 | 录屏软件本身已在缩放，两套镜头打架，画面晃，用户明确说不舒服 |
| 渐变光晕、跳动音柱、药丸标签、居中对称的“标题+副题+引语+页脚” | 一眼模板，“AI 感太重” |
| 半透明卡片、贴边缺口卡片 | 见上，不精致 |
| 橙/朱红到处用 | 变成警示色；强调只能有一个 |
| 字幕压在界面上、字幕离进度标签 <30px | 读不清、挤 |
| 用缩小后的 4K 去比清晰度 | 看不出差别。要用原生像素裁同一块区域，和 1080p 放大后并排比 |

## 4K 与管线要点

- 源录屏 3226×2160 时，画板按 2× 渲（2972×1672，画布 3840×2160）；实测录屏里的界面文字提升有限（源本身偏软），字幕/卡片/进度线的边缘提升明显。要对用户如实说。
- 需要带 libass 的 `ffmpeg-full`；系统 ffmpeg 没有 `ass`、`drawtext`。
- `loudnorm` 会把音频升到 96/192 kHz；拼接封面片段前必须 `aresample=44100`，否则 concat 后时长和音频全乱（实测 123 s 变 268 s）。封面片段与正片的编码参数、分辨率、帧率必须一致才能用 concat demuxer `-c copy`。
- 脚本里用 `declare -A` 等 bash 语法时文件头写 `#!/usr/bin/env bash` 并用 `bash run.sh` 运行；macOS 的 `sed -i` 要加 `''`，批量改文本优先用 Python。
- 光标追踪与点击：`scripts/cursor_track.py`（需 opencv，用 `uv venv` 装在临时目录）。箭头光标可追，手形/I 形光标追不到，要看帧手填坐标。

## 验收（先样张后全量）

1. 先渲一帧静态样张：开场、字幕两行 + 进度线、章节卡、片尾，给用户看，再渲全片。
2. 抽帧：开场至少 4 个时刻（看逐字高亮同步）、章节卡入场 4 帧（看缓动与错峰）、进度圆点是否压在线中心、最长英文行是否出框、片尾搜索三个阶段。
3. 响度用 `ebur128` 测；时长用 `ffprobe` 比对（拼接后每条流都要看）。
4. 没从头到尾看听过就说没有；不把抽帧说成人工复核。
